# G4_Blender changelog

## v2.1.2

- Added independent G4PKM model export with separate geometry and platform textures.
- Added effect previews for layered textures, masked layers and camera-distance fading.
- Improved event effect placement, particle previews and material transparency handling.
- Improved map materials and reduced unwanted outline overlays.

## v2.1.1

- Fixed Windows model exports that failed with an unknown compression option when DirectXTex was installed as `texconv.exe`.
- Moved temporary DDS files into a separate folder to protect existing textures with the same name.
- Added support for both `.dds` and `.DDS` output from the texture converter.
